    83→## 🌸 Overview
    84→
    85→**MiruroAPI** is a serverless anime data API that fetches real-time information from **AniList GraphQL** and streaming data from **Miruro providers** — including anime details, episode lists, M3U8 streaming URLs with subtitles and skip timestamps, search, filtering, characters, and more — all through a clean REST API with zero database.
    86→
    87→> 💡 No database, no auth, no complex setup. Just deploy to Vercel and you have a production API.
    88→
    89→### Why MiruroAPI?
    90→
    91→- 🎬 **46 Endpoints** — Complete anime data coverage
    92→- 🔍 **Full-Text Search** — Search anime by keyword with suggestions
    93→- 🎭 **Characters & Voice Actors** — Full character data from AniList
    94→- 🎯 **Advanced Filtering** — Genre, year, season, format, sort
    95→- 🏆 **Trending & Popular** — Discover what's hot right now
    96→- 📅 **Airing Schedule** — See what's airing on any date
    97→- 📡 **12 Streaming Providers** — M3U8 streaming sources
    98→- ⏭️ **Skip Timestamps** — OP/ED skip data
    99→- 🎭 **Character & Staff Search** — Search characters and staff by name
   100→- 🎬 **Batch Episodes** — Fetch multiple episode sources in parallel
   101→- ⚡ **Smart Caching** — In-memory Map with configurable TTL
   102→- 🔒 **CORS Enabled** — Works from any frontend, no proxy needed
   103→- 🚀 **Zero-Config Deploy** — One click to Vercel, or run standalone with Express
   104→
   105→### 🔄 Self-Healing System (v2.3.2)
   106→
   107→When Cloudflare blocks streaming requests, the API automatically tries fallback methods:
   108→- **Direct** → Mirror rotation across 4 domains (miruro.to, miruro.ru, miruro.bz, miruro.tv)
   109→- **ScraperAPI** → Proxy bypass via premium residential IPs ($49/mo)
   110→- **FlareSolverr** → Self-hosted browser proxy
   111→
   112→Zero-config: works out of the box. Add `SCRAPER_API_KEY` env var for automatic Cloudflare bypass (requires ScraperAPI premium plan for protected domains).
   113→
   114→### ⚠️ Streaming Status
   115→
   116→> **Streaming endpoints (`/api/episodes`, `/api/watch`, `/api/sources`, `/api/stream`) return 500 errors when Cloudflare blocks pipe requests.**
   117→>
   118→> This is expected behavior on Vercel's free tier. Cloudflare's bot protection blocks requests from datacenter IPs (including Vercel's). Metadata endpoints (search, info, trending, etc.) work perfectly — only streaming is affected.
   119→
   120→| What Works | What's Blocked |
   121→|:---|:---|
   122→| Search, suggestions, filter | Episodes, sources, stream |
   123→| Info, characters, relations | Watch, download |
   124→| Trending, popular, schedule | All pipe-dependent endpoints |
   125→| Genres, tags, calendar | Streaming provider data |
   126→| All AniList-backed endpoints | |
   127→
   128→**To fix streaming**, set one of these environment variables in Vercel:
   129→
   130→```bash
   131→# Option 1: ScraperAPI (requires premium plan — $49/month)
   132→SCRAPER_API_KEY=your_scraperapi_key
   133→
   134→# Option 2: FlareSolverr (self-hosted, unlimited)
   135→FLARESOLVERR_URL=http://your-flaresolverr-host:8191
   136→```
   137→
   138→See [How to Fix Streaming](#-how-to-fix-streaming-issues) in Troubleshooting below.

   304→## 🏗️ Architecture
   305→
   306→### Request Flow
   307→
   308→| Stage | Component | Description |
   309→|:-----:|-----------|-------------|
   310→| 1 | **Client** | Browser, app, or `curl` sends request |
   311→| 2 | **Express Server** | Routes request, applies CORS + security headers + rate limiting |
   312→| 3 | **Cache Check** | In-memory Map with TTL — hit = instant response |
   313→| 4 | **Fetch Data** | AniList GraphQL or Miruro pipe endpoint |
   314→| 5 | **Decode** | Pipe responses decoded: base64url → gunzip → JSON |
   315→| 6 | **Cache + Respond** | Store in cache, return JSON response |
   316→
   317→### Caching Architecture
   318→
   319→```mermaid
   320→flowchart TD
   321→    A["📥 Request"] --> B{"🧠 Memory Cache<br/>(Map + TTL)"}
   322→    B -- HIT --> C["⚡ Return Cached<br/>~50ms"]
   323→    B -- MISS --> D["📡 Fetch from<br/>AniList / Miruro"]
   324→    D --> E["🔍 Decode<br/>base64url + gzip"]
   325→    E --> F["💾 Cache Result<br/>(1-5 min TTL)"]
   326→    F --> G["📤 Return Fresh"]
   327→
   328→    style A fill:#1e1e2e,stroke:#a78bfa,color:#f1f5f9
   329→    style B fill:#1e1e2e,stroke:#f43f8e,color:#f1f5f9
   330→    style C fill:#1e1e2e,stroke:#22c55e,color:#f1f5f9
   331→    style D fill:#1e1e2e,stroke:#6366f1,color:#f1f5f9
   332→    style E fill:#1e1e2e,stroke:#06b6d4,color:#f1f5f9
   333→    style F fill:#1e1e2e,stroke:#a855f7,color:#f1f5f9
   334→    style G fill:#1e1e2e,stroke:#22c55e,color:#f1f5f9
   335→```
   336→
   337→> 💡 Serverless functions have read-only filesystems except `/tmp`. The cache uses in-memory `Map` which survives across warm invocations.

   442→| `PRU_PROXY_KEY` | `a54d389c...` | PRU proxy URL XOR key (hex, 32 chars) |
   443→| `SCRAPER_API_KEY` | — | ScraperAPI key for Cloudflare bypass (requires premium plan, $49/mo) |
   444→| `FLARESOLVERR_URL` | — | FlareSolverr URL for browser-based bypass (e.g., `http://127.0.0.1:8191`) |
   445→
   446→> ⚠️ **Required for production:** Set `ALLOWED_ORIGINS` to restrict CORS. Set `PIPE_OBF_KEY` and `PRU_PROXY_KEY` for pipe decoding.
   447→>
   448→> 📺 **For streaming:** Set `SCRAPER_API_KEY` (requires ScraperAPI premium plan) or `FLARESOLVERR_URL` (free, self-hosted) to bypass Cloudflare bot protection. See [How to Fix Streaming Issues](#-how-to-fix-streaming-issues).

   480→# Step 1: Get episodes (returns provider slugs)
   481→curl "https://mirurotvapi.vercel.app/api/episodes/20"
   482→
   483→# Step 2: Get streaming sources (pass provider + anilistId + category + slug)
   484→curl "https://mirurotvapi.vercel.app/api/watch/kiwi/20/sub/animepahe-1"
   485→
   486→# Step 3: Play M3U8 in any HLS player
   487→# Use hls.js, video.js, or native <video> with hls support
   488→```

   490→### Sub & Dub Switch
   491→
   492→Providers return both `sub` and `dub` episode lists:
   493→
   494→```javascript
   495→const eps = await fetch("/api/episodes/20").then(r => r.json());

   497→
   498→// Pick sub or dub
   499→const subEps = kiwi.sub;  // [{ id: "watch/kiwi/20/sub/anikoto-1", ... }]
   500→const dubEps = kiwi.dub;  // [{ id: "watch/kiwi/20/dub/...", ... }]
   501→
   502→// Get stream URL
   503→const stream = await fetch(`/api/watch/kiwi/20/sub/animepahe-1`).then(r => r.json());
   504→// stream.results.streams[0].url = "https://...m3u8"
   505→```

  1274→# Step 1: Get episodes (returns provider slugs)

  1511→### 🎬 How to Fix Streaming Issues
  1512→
  1513→Streaming endpoints fail because Cloudflare's bot protection blocks requests from Vercel's datacenter IPs. The pipe endpoint (`miruro.to/api/secure/pipe`) returns HTTP 403 to any request that doesn't come from a residential IP or real browser.
  1514→
  1515→#### Why Does This Happen?
  1516→
  1517→```
  1518→Your App (Vercel) → Cloudflare WAF → miruro.to/api/secure/pipe → 403 Blocked
  1519→```
  1520→
  1521→Cloudflare detects:
  1522→- Datacenter IP ranges (Vercel, AWS, GCP, etc.)
  1523→- Missing browser fingerprint headers
  1524→- Non-residential traffic patterns
  1525→
  1526→#### Fix 1: FlareSolverr (Best — Free, Works!)
  1527→
  1528→FlareSolverr runs a headless browser that bypasses Cloudflare automatically. This is the most reliable fix.
  1529→
  1530→```bash
  1531→# 1. Run FlareSolverr on your own server
  1532→docker run -d --name flaresolverr -p 8191:8191 ghcr.io/flaresolverr/flaresolverr:latest
  1533→
  1534→# 2. Add to Vercel environment variables:
  1535→FLARESOLVERR_URL=http://your-server-ip:8191
  1536→```
  1537→
  1538→**Cost:** Free (self-hosted). Requires a VPS with Docker.
  1539→
  1540→**Requirements:**
  1541→- 1GB+ RAM
  1542→- Public IP address
  1543→- Docker installed
  1544→
  1545→#### Fix 2: ScraperAPI (Paid — $49/month)
  1546→
  1547→ScraperAPI proxies your requests through residential IPs, bypassing Cloudflare.
  1548→
  1549→```bash
  1550→# 1. Sign up at https://www.scraperapi.com/

  1651→curl http://localhost:3000/api/episodes/20

  1656→## ❓ FAQ
  1657→
  1658→<details>
  1659→<summary><b>🔍 How do I search for anime?</b></summary>
  1660→<br/>
  1661→Use <code>/api/search?query=your+search</code>. Results include title, cover, format, status, episodes, and score. For autocomplete suggestions, use <code>/api/suggestions?query=your+search</code> which returns fast suggestions.
  1662→</details>
  1663→
  1664→<details>
  1665→<summary><b>📺 How do I get episode lists?</b></summary>
  1666→<br/>
  1667→Use <code>/api/episodes/:id</code> where <code>:id</code> is the AniList anime ID (e.g., <code>20</code> for Naruto). The response includes all providers with sub/dub episode lists.
  1668→</details>
  1669→
  1670→<details>
  1671→<summary><b>🎯 How does filtering work?</b></summary>
  1672→<br/>
  1673→Use <code>/api/filter</code> with query params. Combine <code>genre</code>, <code>year</code>, <code>season</code>, <code>format</code>, <code>status</code>, and <code>sort</code> for advanced filtering. All params are optional.
  1674→</details>
  1675→
  1676→<details>
  1677→<summary><b>📡 Can I use this in my frontend app?</b></summary>
  1678→<br/>
  1679→Yes! CORS is enabled for allowed origins. Set the `ALLOWED_ORIGINS` environment variable to your frontend domain(s), or use `*` for all origins. Example: <code>fetch('https://mirurotvapi.vercel.app/api/search?query=naruto')</code>
  1680→</details>
  1681→
  1682→<details>
  1683→<summary><b>🔄 How often does the data refresh?</b></summary>
  1684→<br/>
  1685→The cache TTL is 1-5 minutes depending on the endpoint. After that, the next request triggers a fresh fetch from AniList/Miruro.
  1686→</details>
  1687→
  1688→<details>
  1689→<summary><b>🌐 Can I self-host this?</b></summary>
  1690→<br/>
  1691→Yes! Use <code>npm start</code> to run the Express server on any VPS, Docker container, or PaaS. The Vercel serverless functions are optional — <code>server.js</code> handles everything.
  1692→</details>
  1693→
  1694→<details>
  1695→<summary><b>🎬 Which streaming providers are available?</b></summary>
  1696→<br/>
  1697→12 providers: kiwi, pewe, bee, bonk, bun, ally, nun, twin, cog, moo, hop, telli. Not all anime are available on every provider.
  1698→</details>
  1699→
  1700→<details>
  1701→<summary><b>❌ Why are streaming endpoints returning 500 errors?</b></summary>
  1702→<br/>
  1703→Cloudflare's bot protection blocks requests from Vercel's datacenter IPs. The pipe endpoint (<code>miruro.to/api/secure/pipe</code>) returns HTTP 403. To fix this, set <code>SCRAPER_API_KEY</code> (requires ScraperAPI premium plan, $49/mo) or <code>FLARESOLVERR_URL</code> (self-hosted, free) in your Vercel environment variables. See <a href="#-how-to-fix-streaming-issues">How to Fix Streaming Issues</a> above.
  1704→</details>
  1705→
  1706→<details>
  1707→<summary><b>🔍 Why does /api/staff/:id return 404?</b></summary>
  1708→<br/>
  1709→Some AniList staff IDs don't exist or have limited data. Try searching with <code>/api/staff?query=name</code> instead. This is an AniList API limitation, not a bug.
  1710→</details>
  1711→
  1712→<details>
  1713→<summary><b>📊 How do I check if streaming is working?</b></summary>
  1714→<br/>
  1715→Use <code>/api/pipe-health</code> to check which pipe methods are working. It shows the status of Direct, ScraperAPI, and FlareSolverr fallback methods with latency and error details.
  1716→</details>
